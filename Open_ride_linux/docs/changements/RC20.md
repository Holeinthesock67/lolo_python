- PR : à compléter ; revue de code vague 5 (O3-01, O3-02, O3-03) et vague 2 (C7-04, C7-09, C7-10) ; outils de banc seulement, ni engine ni IPC
- CHANGELOG (section « Corrigé ») :
  - Bancs de performance : un budget (images/s, p99, GPU 8/13/16 ms, à-coups, endurance) sans aucune seconde après la chauffe est un échec quand les budgets sont demandés (`sim_bench --native --probe`, `perf_probe --budgets`) ; le libellé dit combien de secondes ont été jugées. Sous Xvfb, toujours en INFO.
  - `perf_probe watch` ignore le fichier d'une séance précédente et attend que l'engine écrive (pour relire une ancienne séance : `perf_probe report`).
  - Recette U18 : « pas de mesure » sur un critère chiffré est un échec, et le code de retour de chaque passage de `sim_bench` est noté (`codes_bancs.json`) et compté.
  - `matrice_boutons` : un mode dont une phase attendue manque (doublure du monde absente, monde pas prêt, run refusée) est « non mesuré », donc en échec ; `trainer_steps` (trainer simulé réaliste) échoue si aucun palier n'a été comparé au modèle ; `recette_v10` rend un verdict « incomplet » (échec) quand la pente envoyée ou le temps gagné manque.
