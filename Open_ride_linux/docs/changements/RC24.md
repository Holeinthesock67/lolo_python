# RC24 : contenus et packs, rien d'effacé ni de coupé sans le dire

- PR : à ouvrir à la reprise ; revue de code vague 4 (K4-01, K4-02, K4-03, K4-05) ; compilateur et `contents.py` du core, ni engine ni IPC
- CHANGELOG (section « Corrigé ») :
  - Thèmes : le ménage de la bibliothèque ne retire plus que les packs installés par `theme-install` (marque `.installe_par_openride`) ; un thème fait à la main ou un dossier de travail reste en place, et rien n'est retiré si le dossier visé n'est pas une bibliothèque de thèmes. Les packs installés avant ce lot ne sont plus retirés tant qu'ils ne sont pas réinstallés. Un thème retiré par le ménage est maintenant dit dans « Réglages › Contenus ».
  - Contenus de départ : la génération des parcours de démonstration ne coupe plus le réseau des autres fils du core (Bluetooth, recherche de lieu, météo) pendant sa durée.
  - Packs de parcours : une trace en erreur dans le dossier des traces ne fait plus afficher « Installation impossible » quand le pack est installé ; le message dit combien de traces sont en erreur.
  - Packs de parcours : une réinstallation forcée garde les fichiers ajoutés à la main dans le dossier du pack (fiche de segments, trace personnelle).
