# RC17 : file des bancs, pré-vol et stabilité des tests (revue de code vague 5, lot O2)

- PR : à venir ; constats : O2-01, O2-02, O2-03, O2-04, O2-05, O2-09, O2-10, O2-13 ; version : outils
- CHANGELOG (section « Corrigé ») :
  - File des bancs : le cache du monde ouvert est séparé par défaut ; le vrai `~/OpenRide/Cache/monde` n'est utilisé
    qu'avec `cache = "reel"` écrit en toutes lettres, et jamais pour une PR qui change le schéma du cache ou la
    génération du monde ouvert ; l'amorce du cache séparé n'écrit plus rien dans le cache réel.
  - File des bancs : un paquet en échec seulement une fois assemblé rend le code 1 (« défaut d'assemblage ») ; une
    fumée de paquet en échec fait rejouer toute la matrice PR par PR ; un banc planté après des lignes de contacts
    est en ÉCHEC ; une branche supprimée ou un réseau coupé ne donne ENVIRONNEMENT qu'à la PR touchée.
  - Pré-vol : un fichier du joueur (`powerups.toml`) est mis de côté avant d'être remplacé, rien n'est posé si une
    étape précédente bloque, `--remettre` remet les fichiers en place ; la tête est comparée à FETCH_HEAD.
  - Stabilité des tests : une suite plantée sans rapport JUnit est listée et rend le code 1.
