Documents de préparation de la version 2.0. Rien de ceci n'est commencé : les séries démarrent après la 1.0, et leurs cahiers de lots seront ajoutés à `docs/lots/00_INDEX.md` à ce moment-là.

| Document | Contenu |

| [PLAN_SERIE_R.md](PLAN_SERIE_R.md) | Série R : mode Cyber-Rogue (décisions, risques, lots R0 à R16) |
| [PLAN_SERIE_T.md](PLAN_SERIE_T.md) | Série T : sprints, montées chronométrées, bonus et bots à profil du mode classique (lots T1 à T16) |
| [PLAN_SERIE_V.md](PLAN_SERIE_V.md) | Série V : progression commune à tous les modes (niveaux, équipement, avatar ; lots V1 à V10) |
| [PLAN_SERIE_W.md](PLAN_SERIE_W.md) | Série W : monde ouvert généré en direct (départ sur un globe, cache local ; lots W0 à W16) |

Ordre des contrats : la série P (décor vivant, vent, aspiration) prend l'IPC v1.2 ; les séries R, T et V ajoutent ensuite la v1.3, et la série W la révision suivante. Les saisons et le cycle jour et nuit de la série P sont eux aussi prévus pour la 2.0.
